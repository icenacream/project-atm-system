# TUP Bank ATM System

A console-based ATM simulation built in C++ for a Data Structures and Algorithms (DSA) course.

---

## Data Structure Used

**ADT List (Array-Based)** — a custom `AccountList` class that stores up to 1,000 accounts using an array, with operations for insert, retrieve, locate, and update.

---

## Features

- Account registration (name, phone, birthdate, PIN, initial deposit)
- PIN authentication with masked input and 3-attempt lockout
- Balance inquiry, withdrawal, deposit, fund transfer, and PIN change
- XOR-encrypted PIN storage
- File-based persistent storage (`.dbf` files)
